# Яхт-клуб SALI

Лендинг яхт-клуба с информацией о яхтах, регатах и команде. Сайт с переключением темы оформления и шрифтов.

## 🚀 Демо

https://denisunderonov.github.io/SALI-CLUB-SITE/

## Технологии

- HTML5 - семантическая разметка
- CSS3 - переменные, Flexbox, Grid
- Vanilla JavaScript для интерактивности
- Google Fonts (Philosopher, Roboto)
- Адаптивная верстка

## Функционал

**Переключение темы:**
- Светлая тема (по умолчанию)
- Темная тема

**Переключение шрифтов:**
- Sans-serif (Roboto)
- Serif (Philosopher)

**Контент:**
- Информация о яхт-клубе
- Каталог яхт с характеристиками
- Раздел о регатах
- Информация о команде
- Галерея изображений
- Разворачиваемые статьи блога

**Разделы:**
- Главная страница с героем
- Карточки яхт
- Блог новостей
- Контактная информация

## Особенности

- Полностью адаптивный дизайн
- Кастомные CSS переменные для тем
- Плавные переходы между темами
- Система переключения шрифтов
- Интерактивные элементы блога
